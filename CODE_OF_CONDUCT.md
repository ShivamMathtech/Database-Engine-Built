# Code of conduct

Be respectful, specific, and constructive. Critique ideas and code rather than attacking people. Harassment, threats, discriminatory abuse, and publishing another person's private information are unacceptable.

Maintainers may remove abusive content and restrict participation when necessary. Reports should go to the repository's published maintainer contact once configured. Do not post a reporter's private details publicly. This project has no invented moderation email address or promised response SLA.
